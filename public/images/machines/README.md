Machine images, one per model, named after the client poster they were cut from (`175.webp` … `200.webp`),
plus `astoria-tanya-r.webp` and `gnb-*.webp` (product photos / flyer supplied in chat).

Each is the whole machine alone — poster background, headings, props and badges removed — as a
transparent 800 × 1000 (4:5) WebP with a soft floor shadow baked in. Tall machines stand on the same
floor line; short/wide ones are centred. The site draws the light `stage` backdrop behind them
(see `src/app/globals.css`), so dark machine bodies keep a visible outline.
The full posters live in `../posters/` and are shown as the brochure on each machine page.

Originals are the client's WhatsApp files (see project notes). To add a new machine, keep the same
format: 4:5, transparent, whole outline inside the frame with margin.
