Machine images, one per model, named after the client poster they were cut from (`175.webp` … `200.webp`).

Each is the machine alone — poster headings, logos and badges removed — feathered onto the shared
dark stage colour `#221610` on an 800 × 1000 (4:5) canvas, so every card lines up.
The full posters live in `../posters/` and are shown as the brochure on each machine page.

To add a new machine, keep the same format: 4:5, machine centred, `#221610` background.
